Objective
Explore how occupancy information can be used to improve HVAC operation.

Concept
Building occupancy data can be used as an input for HVAC control decisions instead of relying exclusively on fixed operating schedules.

Data Inputs
Potential inputs include:

Occupancy data
Indoor temperature
Outdoor temperature
HVAC operating status
Energy consumption
Expected Outcome
Reduce unnecessary HVAC operation while maintaining required indoor conditions.
